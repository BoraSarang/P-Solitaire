# DESIGN.md — 디자인 시스템 (P-Solitaire)
> 언어: 한국어 | 프로필: **custom** | 플랫폼: game (macOS 데스크톱, Swift 네이티브)
>
> **2026-10-20**: 활성 구현은 `native/`(SwiftUI + Canvas)다. 아래 토큰 값은 네이티브 `Theme.swift`/`Drawing.swift`에 그대로 옮겨졌고, `solitaire.py`·`BACKGROUNDS` 같은 표기는 동결된 파이썬 판의 역사적 이름이다.
>
> **v0.4.0 마감**: 스페이드/클럽 도형 개선 · 위 카드/드래그 카드 그림자 · 탁자 옅은 그라데이션 · 테마에 맞춘 타이틀바 · 카드 이동 비행/스냅백(애니메이션 끄기) · 시스템 사운드(끄기) · 보드/상태줄 VoiceOver label/value/hint · 상태줄 고정폭 숫자. 줌은 100~200% 5단계이며 그리기·판정은 1x 논리 좌표, 화면에 낼 때만 배율을 곱한다.
>
> **전적 창(v0.4.1)**: 620px 고정 폭. 게임명만 가변·왼쪽, `판`·`승`·`승률`·`최고 시간`·`최고 점수`는 고정 폭·오른쪽 정렬. 표 머리글과 값은 같은 열 선에 맞추고, 현재 게임은 accent 막대+`현재` 배지로 표시한다. 창 제목 `전적`과 중복되는 큰 내용 제목은 두지 않는다.
>
> **드래그(v0.4.2)**: 직접 끌어 옮기는 카드는 포인터를 즉시 따라가고, 손을 뗀 순간 목적지에 놓인다. 원래 자리에서 목적지로 다시 날아가는 비행 연출은 **직접 드래그에는 쓰지 않는다**(더블클릭 자동 이동에만 사용).
>
> **이름·그림자(v0.5.0)**: 앱 이름은 `P-Solitaire`, 번들 ID는 `com.borasarang.P-Solitaire`, 로그는 `~/Library/Logs/P-Solitaire.log`. 카드 그림자는 **카드 전체 실루엣에만** 적용한다. 카드 앞면을 그림자 레이어에 통째로 넣으면 하트 핍마다 그림자가 생겨 핍 주변에 동그란 테두리처럼 보이므로, 그림자 실루엣을 먼저 깔고 그 위에 앞면을 그린다.
>
> **화면 버튼·배경음·쉬는 카드(v0.6.0)**: 보드와 상태바 사이에 **46px 컨트롤 바**(새 게임·취소·힌트 / −·배율·+)를 둔다. 창 높이는 574 → **620**, 보드 영역은 540 그대로. 배경음 5곡(Kevin MacLeod, CC BY 4.0)을 `AVAudioPlayer` 로 재생하고 설정 **소리**에서 사용·곡·반복·볼륨을 고른다. 카드 그림자는 **실제로 집었거나 나는 카드에만** 준다 — 쉬는 위 카드에도 옅은 그림자를 두르면 집지 않았는데도 집은 것처럼(모서리에 둥근 그늘처럼) 보이기 때문이다.

## 1. design_profile
- **custom** — 클래식 마이크로소프트 솔리테어의 룩(초록 테이블 + 도형 카드)을 자체 토큰으로 재현한다.
  플랫폼 디자인 스킬(native) 대신 이 문서의 토큰 일관성만 검증한다.

|---|---|---|---|---|---|

- 창 높이는 세 게임 모두 **620**(= 태블로 154 + 보드 540 + 컨트롤 바 46 + 상태바 34 + 10, v0.6.0). 보드 영역은 540 그대로이고 컨트롤 바만큼 창이 46px 높아졌다. 프리셀은 24×11 = 264 로 `TABLEAU_AREA_H` 와 정확히 맞고, 12장 이상 열은 자동 축소된다.
- 스파이더 앞면 간격은 24px(묶음 맨 위 카드를 잡기 쉽도록) — 긴 열(6장 뒤집힘 + 11장 앞면 = 42 + 264 = 306 > 264)은 비례 축소된다.
- 위 줄 구성은 `top_refs()` 가 게임에서 직접 계산한다(클론다이크 스톡·웨이스트 + 파운데이션 4 · 프리셀 프리셀 4 + 파운데이션 4 · 스파이더 스톡 + 파운데이션 8). 위 줄의 열 번호는 **겹쳐도 더하지 않고 그대로** 센다(같은 열 폭 안에 들어가야 창 밖으로 나가지 않는다).
- 열이 길어지면 간격을 자동으로 줄인다(`layout()`): 필요 높이 > `TABLEAU_AREA_H`(=264)일 때 비례 축소(뒷면 ≥3, 앞면 ≥8). 실제 클론다이크 최대는 6장 뒤집힘 + 7장 앞면 = 정확히 264라 축소는 안전망이다.

## 3. 카드 도형
- 무늬는 **글꼴 글리프를 쓰지 않고** 폴리곤·원으로 그린다(♠ 다각형 + 대각선 기둥, ♥ 4점 곡선, ♦ 마름모, ♣ 원 3개 + 대각선 기둥). 글꼴에 따라 무늬가 깨지는 문제를 피한다.
- 앞면: 흰 둥근 사각형 + 테두리, 왼쪽 위·오른쪽 아래 코너에 숫자와 작은 무늬(코너 기둥은 x 7~22px 로 좁게), 가운데는 숫자 카드면 핍 배열·J/Q/K면 액자 + 큰 글자 + 무늬.
- 핍 배열(`PIPS`)은 가로 0/0.5/1, 세로 0~1 비율 좌표로 정의한다. **9·10은 핍을 16px로 줄이고 영역을 안쪽(x±26, y±26)으로** 두어 코너 숫자("10")와 겹치지 않게 한다.
- 뒷면: 테마 색 둥근 사각형 + 안쪽 둥근 사각형 + 무늬 + 가운데 표식(겹친 더미는 2px씩 어긋나게 그린다). 무늬는 `draw_card_back()` 이 `back_style` 로 갈라 `draw_back_lattice`(격자)·`draw_back_rays`(햇살 12° 간격)·`draw_back_dots`(마름모 13×10 격자) 중 하나를 그린다.
- **묶음 집기 표현(pick)**: 집을 수 있는 것은 **그 열의 맨 위 카드까지 규칙이 이어지는 묶음**뿐이다(`pick_whole()`). 규칙(클론다이크·프리셀 색 교대, 스파이더 같은 무늬)이 중간에 끊기면 그 카드는 집히지 않고, 위에 덮인 카드부터 옮겨야 한다 — 화면은 집지 못한 채 이유만 안내한다. 실제로 떼어내는 카드 수는 `move()` 가 같은 계산(`group_run()`)으로 정한다.
  - 예전에는 규칙이 끊기는 자리에서도 "거기까지" 잘린 묶음(심하면 한 장)을 집어 중간 카드만 쏙 빼낼 수 있었다 — MS 규칙과 다르고, 스톡을 돌려 끊긴 스파이더 열·무작위 배분 프리셀에서 실제로 생기던 버그였다
- **묶음 규칙 안내**: 카드를 집으면 상태줄 오른쪽에 `묶음 N장`(여러 장, 1.5초), 집지 못하면 이유 한 줄(4초)을 보여 준다(`set_hint()`·`BaseGame.group_limit_note()`).
  | 못 집는 이유 | 문구 | 게임 |
  |---|---|---|
  | 묶음 규칙(색)에서 끊김 | `색이 다르면 한 묶음으로 옮기지 못합니다` | 클론다이크 · 프리셀 |
  | 묶음 규칙(무늬)에서 끊김 | `무늬가 다르면 한 묶음으로 못 옮깁니다 (게임 → 스파이더 묶음 이동)` | 스파이더(기본) |
  | 위 카드가 아예 이어지지 않음 | `위에 덮인 카드부터 옮겨야 합니다` | 세 게임 공통(`BURIED_TEXT`) |
  | (없음) | — | 스파이더 "무늬 상관없이" — 묶음 규칙으로는 막히지 않는다 |

  - 폭 실측(2026-10-19, 창 953px, Apple SD Gothic Neo 12pt): 오른쪽에 쓸 수 있는 폭 **440px**, 스파이더 새 문구 필요 **430px**(여유 10px) · 클론다이크 **263px** · `위에 덮인 카드부터 옮겨야 합니다` **217px**. 점수·시간이 아주 길어지면 여유가 0px까지 줄어 T-010 후보로 남겨 두었다(문구를 더 줄이려면 `(게임 → 스파이더 묶음)`=426px · `(게임 → 묶음 이동)`=398px).

## 4. 화면 구성
```
┌────────────────────────────────────────────┐
│ [스톡][웨이스트]   [F][F][F][F]            │  ← 위 줄(TOP_Y) — 게임마다 구성이 다르다
│ 1  2  3  4  5  6  7                        │  ← 태블로 7열(TABLEAU_Y)
│ …카드…                                     │
├────────────────────────────────────────────┤
│ [새 게임] [취소] [힌트]          [− 100% +] │  ← 컨트롤 바 46px
├────────────────────────────────────────────┤
│ 클론다이크 · 점수 … · 시간 … · 이동 … · 3장 넘기기   F2 …│  ← 상태바 34px
└────────────────────────────────────────────┘
```
- **위 줄 구성**(`top_refs()`): 클론다이크 `스톡 · 웨이스트 · (한 칸 띄고) 파운데이션 4` · 프리셀 `프리셀 4 · 파운데이션 4`(간격 없이 8열에 꽉 참) · 스파이더 `스톡 · 파운데이션 8`
  - 파운데이션은 태블로 오른쪽 끝에 맞춘다(`col = max(col, columns - foundations_count)`) — 프리셀은 자리가 빠듯해 띄우지 않는다.
- **상태바**: 클론다이크 `점수·시간·이동·N장 넘기기` · 프리셀 `시간·이동·빈 프리셀 N칸·남은 카드 N장` · 스파이더 `점수·시간·이동·완성 N/8·스톡 N번`
- **컨트롤 바**: 왼쪽 `새 게임 · 취소 · 힌트`, 오른쪽 `− · 현재 배율 · +`. 메뉴·단축키와 같은 `GameController` 메서드를 불러 결과·확인 대화상자·비활성 조건이 같다. 배경은 테마 `statusBg`, 위에 1px 밝은 선.
- **배경음**: 설정 **소리**에서 효과음·배경음 사용·곡(5곡)·반복(안 함/한 곡/목록)·볼륨을 고른다. 기본값은 켬 · 첫 곡 · 목록 반복 · 35%. 재생 실패는 `E-MACOS-AUDIO-0001/0002` 로그와 상태바 안내.
- **스파이더 스톡**: 남은 배분 횟수를 뒷면 더미 오른쪽 위에 숫자로 표시(10장씩 5회)
- **완성 세트**(스파이더): 파운데이션 칸에 K 카드를 보여 주고, 개수는 상태바 `완성 N/8` 로 확인한다
- **힌트**: 대상 카드·자리에 노란 테두리를 3번 깜빡인다(200ms 간격).
  - 보여 줄 수를 고르는 방식은 **해답 탐색**이다. 예전처럼 "지금 둘 수 있는 한 수"를 점수로 고르면 프리셀↔태블로 왕복이나 스톡 넘기기만 반복하므로, 현재 판에서 이기는 줄을 최선 우선 탐색으로 찾아 **첫 수**를 낸다.
  - 결과는 `.solved`(해답) · `.impossible`(끝까지 살펴도 이기는 줄 없음) · `.unknown`(시간·노드 한도)으로 나뉜다. 화면은 각각 "이기는 해답 N수 중 첫 수입니다" · "이 판은 지금 상태에서 더는 이길 수 없습니다" · "제한 시간 안에 확실한 해답을 찾지 못했습니다"로 답하고, 뒤의 두 경우에는 **아무 수도 권하지 않는다**.
  - 탐색 예산은 FreeCell 1.5초/25만 상태, Klondike 2.5초/40만 상태, Spider 3초/60만 상태. 백그라운드에서 돌고 상태줄에 "이기는 해답을 찾는 중…"을 보여 주며, 결과는 **판 스냅숏이 그대로일 때만** 반영한다.
  - 풀리는 스파이더 판은 배분할 때 찾은 해답을 `Spider.startLayout.solution` 에 저장해 두고, 그 경로 위에서는 탐색 없이 다음 수를 바로 안내한다. 경로에서 벗어나면 자동으로 탐색으로 넘어간다.
- 드래그: 집은 카드를 맨 위로 올리고(`tag_raise`), 놓을 수 있는 자리를 노란 테두리로 표시한다. 겹침 면적이 카드의 30% 이상인 자리를 목표로 삼는다. 그림자는 **집은 카드·나는 카드·우승 연출에만** 주고, 쉬는 카드는 평평하게 그린다.
- 우승: 대화상자(시간·이동·점수·보너스) → 카드가 파운데이션에서 튀어나와 바닥에 튕긴다(중력 0.55, 반발 0.78, 45ms 간격).
- **확대(배율)**: 그리기·판정은 1x 논리 좌표 그대로 두고 `redraw()` 끝에서 `zoom_items()` 가 `canvas.scale()` 로 좌표를, 반복문에서 **선 두께**를, `update_fonts()` 가 **글꼴 크기**를 배율만큼 키운다. 카드 내부 여백(코너 7px·안쪽 테두리 5/8/17px·격자 11px 등)도 좌표라서 함께 확대된다. 드래그·힌트·드롭 표시·우승 연출처럼 `redraw()` 뒤에 만드는 항목은 만든 직후 같은 함수로 태그만 확대한다.
  - 창·캔버스·상태바는 `apply_window_size()` 가 배율에 맞춰 다시 잡는다. 화면 여유는 가로 24px·세로 80px(메뉴 막대·타이틀바·독) — 이 화면(1800×1169)에서 세 게임 모두 **175%**(최대 스파이더 1668×1005)까지 들어가고, 200%는 세로(1148px)가 넘어 거절된다.

## 5. 시스템 UI (프로필 무관 native)
- **앱 번들·메뉴 막대**: 실행 파일이 번들 안(`Contents/MacOS/P-Solitaire`)에 있어야 macOS 가 `CFBundleName`("P-Solitaire")을 읽는다 — 런처가 프레임워크의 `Python.app` 스텁을 exec 한다(스텁이 없으면 시스템 파이썬으로 폴백, 이때는 메뉴 막대가 "Python"으로 보일 수 있다). 창 제목도 `P-Solitaire — 클론다이크`(게임 이름) 형식이다.
- **디버그 패널**(`Cmd+Shift+D`): 떠 있는 창(항상 위), 성능·최근 로그 12줄·오류 수, "오류 수 초기화"·"닫기" 버튼. 닫기(X)는 숨김 처리.
- 시스템 대화상자(전적·도움말·우승·힌트 없음)는 `tkinter.messagebox` 를 그대로 쓴다.
- 오류 문구는 상태바 오른쪽에 `⚠` 와 함께 6초 표시(`error_message_ko.json`), 로그에는 `[ERROR] E-GAME-…`.

## 6. 접근성 최소선
- 색만으로 구분하지 않는다: 무늬는 **모양**으로, 놓을 자리는 **테두리**로 표시한다.
- 모든 조작에 키보드 대체 수단이 있다(새 게임 `F2`, 취소 `Ctrl+Z`, 넘기기 `Space`, 힌트 `H`, 자동 완성 `A`, 모드 `D`, 게임 전환 `Cmd+1/2/3`, 자동 기능 `Cmd+Shift+A`).
- 글자는 고정 크기지만 상태바·카드 모두 큰 대비의 굵은 글꼴을 쓴다. 창 크기 조절(자유 리사이즈)은 지원하지 않는 대신 **확대 배율 5단계**(100~200%, `Cmd+=`/`Cmd+-`)로 카드·글자·상태줄을 함께 키운다 — 화면에 들어가는 배율만 쓸 수 있다(T-007).
- 자동 기능은 모두 끌 수 있다(끄면 사용자가 직접 조작한 것만 반영된다) — 더블클릭 자동 이동·이동 뒤 자동 올리기·게임 끝 자동 완성. 기본값은 앞의 둘 켜짐, 자동 완성 꺼짐.
