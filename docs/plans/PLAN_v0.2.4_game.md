## 1. 목표 (1줄)
상태줄 **안내 문구가 일찍 사라지던 버그**를 고치고(`set_hint()` 예약 취소 누락),
검사기(테스트)가 **무작위로 흔들리던 2건**을 없애 검증을 믿을 수 있게 만든다.

## 2. 범위
- **포함**
  1. **버그 수정 — 안내 문구 조기 소멸**: `set_hint()` 가 새 문구를 띄울 때 앞선 문구의 되돌리기 예약(`after`)을 취소하지 않아, 앞선 짧은 안내의 타이머가 나중 문구를 덮어썼다
     - 예) 카드를 집어 `무늬가 다르면 한 장씩만 옮깁니다 …`(4초)가 뜬 직후 0.0~0.3초 안에 `F2 새 게임 · …`(기본 안내)로 돌아가 "왜 한 장만 집혔는지" 가 사라졌다
     - `solitaire.py`: `self.hint_after`(예약 id) 추가 · `set_hint()` 가 먼저 취소 · `restore_hint()` 가 예약 정리 · `cancel_animations()`(새 게임·같은 판 다시 시작·게임 전환)가 예약을 정리하고 기본 안내로 되돌림
  2. **검사 흔들림 제거(2건)** — 같은 검사를 20회 반복해 20/20 통과 확인(고치기 전: 82개 중 0~2개가 무작위 실패)
     - `프리셀 칸으로 끌어놓기`: 무작위 배분에서 뽑은 카드가 A이면 기본 켜짐인 **이동 뒤 자동 올리기**가 그 A를 파운데이션으로 올려 실패(앱은 정상). 판을 고정(9♠·4♥)해 검사가 흔들리지 않게 함
     - `무늬가 섞이면 한 장만 집힌다(MS 규칙)`: 1번 버그가 원인 → 수정으로 해결
  3. **새 검사 2개**: `나중 안내가 앞선 되돌리기를 취소`(버그 고정) · `프리셀 칸에 놓은 A는 자동 올리기로 파운데이션`(동작을 명시적으로 검사 — A가 올라가면 2까지 연쇄로 올라갈 수 있어 "A가 들어 있다"로 판단)
  4. 문서 갱신(CHANGELOG·TODO·README·DESIGN·CHANGELOG 집계·AGENTS.local.md·세션) + 앱 번들 버전 v0.2.4(빌드 24)
- **제외**
  - 규칙·기본값·난이도 변경 없음(스파이더 묶음 이동은 v0.2.3 그대로)
  - 자동 올리기가 프리셀 칸의 A까지 올리는 동작은 **MS 동작과 같고 끌 수 있는 옵션**이므로 유지(문서로만 안내)
  - T-010(상태줄 오른쪽 문구 폭 여유) 등 나머지 후보는 `docs/TODO.md` 에 남긴다

## 3. 설계 결정
| 결정 | 이유 |
|---|---|
| 예약 id 를 들고 다니며 취소한다 | Tk 의 `after()` 는 취소하지 않으면 그대로 살아 있다. 문구를 바꿀 때마다 이전 예약을 지워 **가장 최근 안내가 정해진 시간만큼** 보이게 한다 |
| `cancel_animations()` 에서 문구도 기본값으로 되돌린다 | 새 게임·게임 전환은 새 판이므로 단축키 기본 안내부터 시작하는 편이 자연스럽다(이전 안내가 남아 있지 않게) |
| 검사는 **판을 고정**한다 | 무작위 배분 + 기본 켜짐 자동 기능이 겹치면 검사가 흔들린다. 검사하려는 동작만 남기고 판을 명시적으로 구성한다 |
| 자동 올리기 동작은 바꾸지 않는다 | "이동 뒤 자동 올리기"는 사용자가 끌 수 있고, A를 프리셀에 두는 일은 거의 쓸모가 없다. 동작을 바꾸는 대신 **검사로 고정**하고 문서에 적는다 |
