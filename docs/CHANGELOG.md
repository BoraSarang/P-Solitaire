## v0.5.1 (native, 미배포) — 2026-10-27
- **스파이더 "풀리는 판만"** — 사용자 요청("스파이더 풀리는 판만 나오게"). 새 스파이더 판은 **1·2·4무늬 모두 반드시 풀 수 있는 배분**으로 나온다. 기본값은 **켬**
  - **방식**: 1무늬 판을 최선 우선 탐색(빔 아닌 A*형)으로 풀어 실제 해답 수순을 얻은 뒤, 해답에서 **함께 움직인 카드가 같은 무늬**가 되도록 무늬를 다시 배정한다. 그러면 2·4무늬 판도 같은 수순으로 반드시 이긴다. 4무늬는 세트 2개씩, 2무늬는 4개씩, 1무늬는 전부 스페이드
  - **검증**: 만들어진 배분은 실제 `Spider` 규칙으로 해답을 한 수씩 다시 두어 **이김을 확인한 뒤에만** 화면에 올린다. 실패하면 다음 판 번호로 자동 재시도(회차당 4번 × 최대 3회차, 그래도 없으면 이미 검증된 번호로 마지막 시도)
  - **화면**: 만드는 동안 보드를 덮는 **"풀리는 판을 만드는 중…"** 안내(입력 차단). 보통 0.1~0.5초, 어려운 판은 3~5초(릴리스 기준 20판 측정에서 실패 0회, 평균 1.5초)
  - **설정**: `게임 → 스파이더 풀리는 판만` · `⌘,` 설정의 같은 항목. 끄면 예전처럼 무작위 배분
  - **판 번호**: 표시되는 번호는 실제 배분을 만든 번호다. 그 번호를 `⇧⌘O`로 다시 넣으면 **같은 풀리는 판**이 재현된다. 풀리지 않는 번호를 넣으면 안내하고 판을 바꾸지 않는다
  - **다시 시작/이어하기**: 시작 배치를 `Spider.startLayout`에 기억하고 저장 파일에도 `spiderStart`로 남겨, 다시 시작하거나 앱을 껐다 켜도 **같은 풀리는 판**이 유지된다
  - 솔버는 백그라운드에서 돌고, 카드 일련번호는 여러 스레드에서 만들어도 겹치지 않게 잠금으로 보호했다
