## 1. 목표 (1줄)
사용자가 실제로 플레이하며 찾은 **버그 2건(프리셀 잘림·묶음 이동)** 을 고치고,
**자동 기능 On/Off** 와 **테마(배경·카드 뒷면 각 3종)** 를 더한다.

## 2. 범위
- 사용자 요청(그대로)
  1. "프리셀 창이 오른쪽이 잘리네" → 창 밖으로 나가는 위 줄 계산 수정
  2. "여러장 한꺼번에 못 움직이는 건가??? 한장씩 밖에 움직일 수 없네?" → 묶음 집기 규칙 수정
  3. "자동 기능 On/Off 할 수 있게 해줘"(더블클릭 자동 이동·이동 뒤 자동 올리기·자동 완성) → 설정 + 메뉴 + 단축키
  4. "카드 이미지랑, 배경도 두가지 정도 더 만들어줘" → 배경 3종 · 카드 뒷면 3종, 독립 선택·저장
- **포함**
  1. `top_refs()` 의 위 줄 열 계산 수정 — `col = max(col + 1, …)` → `col = max(col, …)`
  2. 코어 `BaseGame.run_from()` 신설 + 세 게임 `pick()` 이 "잡은 카드부터 이어지는 만큼(최소 1장)"을 돌려주도록 수정
     + `move()` 의 `del tableau[i][index:]` → `[index:index + len(run)]` (집은 접두만 떼기)
  3. 스파이더 앞면 띠 21 → 24px(잡기 쉽게) — 긴 열 자동 축소 로직은 그대로
  4. `settings["auto"] = {double, collect, finish}` · 메뉴 **게임 → 자동 기능**(모두 켜기/끄기 + 개별) · `Cmd+Shift+A`
  5. `BACKGROUNDS`(green·blue·dark) · `BACKS`(lattice·rays·dots) · 메뉴 **보기** 라디오버튼 · `settings["theme"]`
  6. 설정 정규화(`normalize_settings`) — 알 수 없는 값은 기본값으로, 옛 파일도 안전하게
  7. 도움말·README·DESIGN·CHANGELOG·TODO·API 문서 갱신 + 캡처 5장(3게임 + 테마 2장)
  8. 앱 번들 재생성(v0.2.1 · 빌드 21)
- **제외**
  - 진행 중인 판 저장(게임 전환은 여전히 새 판), 카드 소리, 창 크기 조절
  - 스파이더 "긴 묶음 잡기"(누른 카드 위쪽까지 확장) — 위 카드가 끼면 아래 카드가 못 움직여 막히는 문제가 있어 MS와 같은 "누른 카드부터"를 유지

## 3. 설계 결정
| 결정 | 이유 |
|---|---|
| 묶음 규칙을 `run_from()` 한 곳에 모은다 | 화면이 집는 묶음과 코어가 옮기는 묶음이 어긋나면 "집히는데 안 옮겨지는" 버그가 된다. `pick()`·`move()` 가 같은 함수를 쓴다 |
| `pick()` 이 `None` 을 덜 돌려준다 | 예전에는 아래 끝까지 규칙이 안 맞으면 `None` → 화면이 종소리만 울려 **카드가 아예 안 집혔다**. 이제 최소 1장은 항상 집힌다 |
| 자동 기능은 UI에서만 처리(코어 무변경) | 규칙(코어)과 편의(UI)를 분리한다 — 코어 테스트는 그대로, 자동 기능은 UI 테스트로 검증 |
| 자동 기능 기본값: 더블클릭 On · 이동 뒤 올리기 On · 자동 완성 Off | MS 기본 감각(더블클릭·자동 올리기)은 켜 두고, 판을 끝내는 자동 완성은 사용자가 켜게 한다 |
| 테마는 배경·뒷면을 **독립** 선택 | 사용자 표현("카드 이미지랑, 배경도 두가지 정도 더")을 각각 3종으로 해석 — 조합이 9가지 |
| 캡처는 창을 앞으로 올리지 않는다 | 사용자가 맥을 쓰는 중일 수 있다(`screencapture -l <창ID>`, `SOLITAIRE_POS` 로 구석 배치) |
