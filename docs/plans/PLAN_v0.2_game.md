## 1. 목표 (1줄)
v0.1 클론다이크에 **프리셀·스파이더**를 더해, 한 프로그램에서 **골라서 플레이**할 수 있게 한다.

## 2. 범위
- 사용자 요청: "FreeCell + Spider 게임도 추가해서 선택해서 플레이할 수 있게 해줘"
- **포함**
  1. 게임 3종 코어 — `BaseGame` 공통 뼈대(점수·이동·undo·시드·요약) + `Klondike` 리팩터 + `FreeCell` + `Spider` + `make_game()` 팩토리
  2. 프리셀 — 8열·52장 전부 앞면·프리셀 4칸·**여러 장 묶음 이동** `(빈 프리셀+1) × 2^(다른 빈 열 수)`·더블클릭 우선순위(파운데이션→태블로→빈 프리셀)·파운데이션 재사용·자동 완성 조건(프리셀 전부 빔 + 모든 열 내림차순)·점수 없음
  3. 스파이더 — 10열·104장(2벌)·난이도 **1·2·4무늬**(기본 1무늬)·스톡 10장×5회·**빈 열이 있으면 딜 거부**·같은 무늬 묶음만 이동·K→A 세트 자동 수거(+100)·점수 500 시작·이동 −1
  4. 게임 선택 UI — 메뉴 **게임 → (게임)** + **`Cmd+1/2/3`**, 스파이더 난이도 하위 메뉴, **마지막 게임·난이도 기억**(시작 창 없음)
  5. 화면 일반화 — 게임별 배치(`STYLE`·`top_refs()`)·창 너비 자동(674/767/953)·상태바·도움말·우승·전적 문구 게임별·스파이더 스톡 남은 횟수 표시
  6. 전적 파일 형식 v2 — 게임별 기록 + 설정, 옛 형식(클론다이크만) 자동 이관
  7. 화면 캡처 3종을 `docs/images/` 에 남겨 눈으로 확인 가능하게 한다
- **제외**
  - 카드 이미지·사운드, 온라인 랭킹, 애니메이션 다양화, 창 크기 조절(→ `docs/TODO.md` T-007)
  - 스파이더 자동 완성(구조상 불필요 — 세트 자동 수거로 대체)

## 3. 설계 결정
| 결정 | 이유 |
|---|---|
| 게임 규칙은 `solitaire_core.py` 에만, 화면은 게임 객체가 알려 주는 값으로 배치 | 게임을 늘려도 화면 코드에 하드코딩이 늘지 않는다(AGENTS.local §4) |
| 카드마다 고유 번호(`Card.card_id`) | 스파이더는 같은 무늬·숫자 카드가 여러 장 → 화면 태그·위치 키가 겹치지 않게 |
| `foundations` 의미를 게임마다 다르게 | 클론다이크·프리셀은 무늬별 4칸(빈 칸 유지), 스파이더는 **완성 세트 목록**(0~8개) → 화면은 `foundation_card()` 로 보이는 카드만 계산 |
| 프리셀 점수 없음 | MS 프리셀은 점수를 매기지 않는다(이동·시간만) |
| 게임 전환은 새 판 | "선택해서 플레이"가 목적 — 진행 중 판 저장은 범위 밖(도움말에 명시) |
| 시작 창 없이 메뉴·단축키 | 사용자 요청(빠른 전환) + 마지막 게임 기억으로 재실행도 자연스럽다 |
